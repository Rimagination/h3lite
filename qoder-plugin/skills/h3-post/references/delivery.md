# 交付

## 默认位置

- 成片默认放 `%USERPROFILE%\Downloads`（本机即当前用户下载目录）；用户当次指定其他目录时以当次为准。
- 中间文件、字幕源文件、拼接列表留在项目目录，不往 Downloads 堆过程文件。
- 不覆盖已有文件；重名时加 `_v2`、`_final` 等后缀。

## 命名

`主题_版本_时长_画幅.mp4`，例如：

- `JOJO风_断罪硬币_三镜版_9s_竖屏.mp4`
- `DeepSeek娘_窗边行星_15s_竖屏.mp4`
- `短剧_樱花第一集_90s_竖屏_双语字幕.mp4`

避免空格与特殊符号；需要中文可以保留，但要确保播放器兼容。

## 交付回执

交付消息里给出：

```text
路径: <绝对路径>
时长: <hh:mm:ss.mmm>
画幅: <宽x高> / <帧率> fps
镜头: <N 个视觉段 / 单次生成或拼接 / 切点>
音轨: <codec> / <采样率> / <声道>
响度: <LUFS> / TP <dBTP>
字幕: <语言/无>
QA: <通过项 / 仍存在的风险>
```

## 交付前

- 成片已完整播放一遍；不是只看首帧；
- 字幕、音频、镜头顺序均核过；
- 文件能在目标机器上打开；
- 需要保留的源镜头与工程文件仍在项目目录。

## 禁止

- 把仍有关键失败项（黑帧、字幕错位、音轨缺失、镜头错序）的文件标为完成；
- 只发一个路径不给规格与 QA 结论；
- 把中间合成文件当作成片交付。
