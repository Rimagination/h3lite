# 音频：响度、层级与混音

## 响度归一

**一条成片只做一次 loudnorm**：无论它是单条多镜生成，还是逐镜拼接后的成片。逐镜归一会把安静段抬高几十 dB，接缝出现抽气、底噪跳变；整条处理才能保留连续的雨声、房间底噪和音乐底床。

验收目标：`I=-14 LUFS, TP=-1.5 dBTP, LRA=11`。编码设置用 `I=-13.7, TP=-1.8`，给 AAC 预留约 0.2–0.3 dB 的真峰值过冲；编码后再实测成片。

```bash
# 第一遍：测量（用编码目标）
ffmpeg -i in.mp4 -vn -af "loudnorm=I=-13.7:TP=-1.8:LRA=11:print_format=json" -f null -

# 第二遍：用第一遍的 measured_* 值；视频流不重编
ffmpeg -i in.mp4 -map 0:v:0 -map 0:a:0 -c:v copy \
  -af "loudnorm=I=-13.7:TP=-1.8:LRA=11:measured_I=<...>:measured_TP=<...>:measured_LRA=<...>:measured_thresh=<...>:offset=<...>:linear=true" \
  -c:a aac -b:a 192k -ar 48000 -ac 2 -movflags +faststart out.mp4

# 第三遍：核对成片（验收目标）
ffmpeg -i out.mp4 -vn -af "loudnorm=I=-14:TP=-1.5:LRA=11:print_format=json" -f null -
```

- 实测示例：源 `-16.64 LUFS / +0.42 dBTP / LRA 7.00`；按 `-13.7/-1.8` 编码后成片 `-13.83 LUFS / -1.55 dBTP / LRA 6.10`。AAC 确实把真峰值抬了约 0.25 dB。
- 源 LRA 低于 11 时不要为了“凑 11”做扩张；LRA 是上限方向，不是必须填满。
- 成片真峰值仍高于 -1.5 时，重编把 TP 再降 0.1 dB；不要用 `alimiter` 补救。
- 只处理音频时视频 `-c:v copy`。
- **不要用 `alimiter` 代替 loudnorm**：本机实测会把峰值压坏、听感发闷。
- 对白优先：先保证台词清楚，再谈整体响度。

## 多镜拼接的音频

- 先拼视频，再整条归一；不要每镜先归一再拼。
- 每镜都有环境声时，在接缝处做 20–50 ms 交叉淡化，或铺一条连续 room tone/BGM；不要用静音补洞。
- 对白跨切点用 J/L cut：下一镜声音提前 2–4 帧进，或上一镜声音延后 2–4 帧出。
- 单次生成多镜的雨声/环境底床本来连续，整条归一即可；不要在每个切点加淡入淡出，除非源音轨本身有爆音。

## 声音四层与空间

- 对白 / SFX / 环境 / BGM 四层；一个动作一个主 SFX，环境保留 2–3 个元素，不要十层叠加。
- 写透视：near/far、画内/画外、隔墙/隔玻璃；画外声可以提前 2–4 帧进入下一场。
- 每个地点铺一条 room tone；接缝用 20–50 ms 交叉淡化，不要用静音补洞。
- 单条成片一条 master track；BGM 写乐器/速度/动态，不写“史诗感”。
- 完整声音设计与调色清单见 [`professional-edit-sound.md`](professional-edit-sound.md)。

## 层级参考

以对白为 0 dB 的参考混音：

| 层 | 电平 |
|---|---|
| 对白 | 0（基准） |
| 拟音/动作 | −1 ～ +1 |
| 环境 | −3 ～ −6 |
| 音乐 | −2 ～ −4 |
| 强调音效 | +1 ～ +3 |

这些是写作与初混方向，不是硬性标准；以试听为准。

## BGM

- 用户没要求就不加音乐。
- 加 BGM 时不得盖过台词；必要时在台词段把音乐降到 −8 ～ −12 dB，或做侧链/手调包络。
- 原生台词镜头不要再叠第二层人声或 TTS。
- 剧集底床可以用同一条 BGM 循环，但接缝处要交叉淡化，避免每镜重启。
- 音乐结尾要与画面结尾一起收，不要硬切。

## 静音与负空间

- 静音是设计手段：在重击前留 0.3–0.8 s 静音，冲击更明显。
- `不要对白` 不等于静音：保留环境与动作音。
- 只有用户明确要求“完全静音”才移除音频流。

## 声音一致性（跨镜音色）

响度达标不等于声音一致。同一个角色在不同镜头忽年轻忽苍老，是音色漂移，不是音量问题。

- 工具：`../scripts/h3_voice_audit.py`，按角色窗口测 F0 中位数 / p10–p90 / 周期性 / 频谱质心 / HF>2 kHz 占比 / dBFS，并汇总极差与半音差。
- 计划 JSON：`[{"character":"A","file":"video/shot05.mp4","start":3.95,"end":7.05,"band":[70,220],"note":"line1"}]`。`band` 是该角色的 F0 搜索带（老年男 70–220、青年女 160–400、念经底床 60–220 一类）。
- 门限：同一角色跨镜 F0 中位数极差 **≤2 个半音（约 12%）**、质心极差 ≤约 25%；同场两个角色 F0 中位数差 **≥3 个半音**，低于此值有合并风险。半音差 `12*log2(f2/f1)`。
- 先测正典样本拿基线，再逐镜比；底床声（念经、雨、嗡鸣）同样审计，全片应来自同一正典源。
- 超标先回 `h3-prompt`/`h3-generate`：改 VOICE 块、拉开选角声学距离、换干净参考样本、只改时长 ±1–2 s 重试。
- 只有用户明确批准才做有限后期修正：窗口化 rubberband（`pitch=X:tempo=1.0:formant=shifted:pitchq=quality:detector=soft:channels=together`）+ 40 ms 等功率交叉淡化，时长漂移 ≤0.05 s，视频流 `-c:v copy`，修正后仍只做一次整条 loudnorm。
- **绝不加第二遍人声、绝不 TTS 补录**；修正只改已有原生人声的音高/共振峰，不新增语音内容。
- 方法与已知坑见 [`../../h3-prompt/references/voice-consistency.md`](../../h3-prompt/references/voice-consistency.md)。

## 验证

1. `ffprobe` 确认音频流、采样率、声道数；
2. `loudnorm` 输出 JSON 核对 integrated/true peak 达标；
3. 戴耳机听：台词是否清楚、接缝是否爆音、BGM 是否压人声；
4. 抽 3 个时间点看音画同步；
5. 交付前重验成片音频流没有被后续滤镜误删。
