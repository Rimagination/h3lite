# 调动作工艺细则与反例台账

本文件是 `h3-whitemodel` 的细则库：六条规范的展开、本机反例、关键帧时间线范例、helper 清单、PoseMy.Art 草稿配方。

## 1. Pose-to-pose + breakdown

专业流程：极端姿势（contact / down / passing）→ breakdown 帧定弧线走向 → 样条补间 → 图形编辑器调 spacing。
反例（本机 v1）：8 个稀疏关键帧 + 每段对称 smoothstep，关节走直线、速度在关键帧处拐角，成片"机器人挥棍"。
修正：挥砍段加 breakdown（t=0.40 中段帧）、预备段加下沉帧（t=0.26）；弧线由帧位决定，插值只负责连续。

## 2. 预备 / 过冲 / 缓冲

- 预备（anticipation）：出招前身体反向蓄力。范例 `crouch(S(A_GUARD,0.15,-0.10), 0.05)`——重心沉 5 cm。
- 过冲（overshoot）：命中后姿势冲过头再回弹。范例 `up(A_STRIKE, 0.07, -0.04)` + 剑尖 `(1.28,0.88,1.16)`。
- 缓冲（settle）：收势前一次微沉降/微起。范例 `up(A_DOWN,0,0.015)`。
三拍缺任何一个，动作就"匀速进出"，能量感归零。

## 3. 接触帧锁脚（foot plant）

溜冰感=踝坐标每帧都在变。规则：迈步只发生在换步帧；站定期间所有关键帧**共享同一踝坐标**。
本机坐标对：攻击者蓄力帧踝 = 斩击帧踝 `(-0.24,-1.05,0.07)/(0.34,0.45,0.07)`；防御者戒备帧踝 = 格挡帧踝 `(-0.22,0.70,0.07)/(0.28,1.85,0.07)`。缠斗（t=0.56）才允许再次换步。
注意连锁效应：锁脚后蓄力帧髋在后、脚在前=腿更屈（蓄力感），这是对的；若腿被拉直说明髋/脚不匹配，调髋不调脚。

## 4. Catmull-Rom 样条

`cr_at(t)` 穿全部关键帧：C1 连续速度 + 自动弧线。端点夹取（clamp）防首末外摆。
稀疏键上 CR 会轻微过冲——多数情况正是想要的（弧线/回弹）；踝部因共享坐标近似平台，残余抖动可接受。

实现陷阱（实测台账）：CR 四项的角色是 (中心1, 前, 中心2, 后)。若按 (前, 中心1, 中心2, 后) 传参，每段实际跨 K[i−1]→K[i+1]，u=0 返回 K[i−1]——每个关键帧结点处整副骨架瞬移一个键距（鸣人片 f48 头-颈距单帧跳 0.28/0.52 m，抽帧目检才暴露）。验收必须包含"结点帧 ±1 抽帧"：关节间距序列在结点处不得出现单帧尖峰。

## 5. 次要运动 / 重叠

头部 IIR 低通（alpha=0.5，约 1.5 帧滞后）：转身、受击时头"甩"一下。
不要滞后胸口和手：胸口滞后会吃掉打击snap，手滞后会令剑与接触点脱同步。
道具次要运动范例：矮桌在缠斗窗（t=0.50–0.62）被带翻 95° 并滑移 0.35 m——"环境演员"比人物多动一层更可信。

## 6. 间距（spacing）调节奏

口诀：时机靠帧位，缓急靠间距。范例：挥砍 breakdown→接触只隔 t=0.04（24 fps 下约 1 帧间隔走完最后一段）= "快斩"；对峙绕步给 t=0.08–0.16 的宽间隔= "缓"。
想改某一拍的猛/缓：挪 KEYS 时间戳，不改插值函数。

## 关键帧时间线范例（室内 10 s，12 键）

```
0.00 对峙        0.08 呼吸微沉      0.16 绕步换边
0.26 预备下沉    0.32 蓄力(锁脚起)  0.40 挥砍breakdown
0.44 接触        0.48 过冲/受击回弹 0.56 缠斗(换步+翻桌)
0.70 扫腿倒地    0.84 收势微起      1.00 定格
```

## helper 清单

- `S(j,dx,dy)` 整体平移；`crouch(j,dz)` 下蹲（上体全沉、盆 0.6、膝 0.3、踝 0）；`up(j,dy,dz)` 上体偏移（下肢不动）；`M(j1,j2,u)` / `MT(p1,p2,u)` 混合。
- 胶囊更新：`scale.z = L/L0` + `to_track_quat('Z','Y')`；剑刃 `to_track_quat('Y','X')` + `scale.y = L`。

## 相机反例

- 65 mm @ 1.3 m：水平覆盖约 0.7 m，两人近身时相机埋进身体（f200 全糊）。改 50 mm @ ≥2 m 解决。
- 固定目标点：动作移出画面。改实时锁双人胸口中心 + 每镜 `target_dz` 微调高度。
-  skinned-mesh Box3 / 骨骼世界坐标自动取景在 PoseMy.Art 里不可靠（骨骼散乱 r=146）；Blender 侧用关节云中心+半径公式可靠。

## PoseMy.Art 免费档草稿配方（非正统，仅快速草稿）

Vue2 app 挂在 `#v-app.__vue__`；沿 `$children` 按 `$options.name` 走到 App 组件；`loadPremadeScene(sceneObj, forceReplace)` 加载场景（`.pma` 是压缩格式，**不能** JSON.parse 直喂）；隐藏视口会暂停 rAF 且 canvas 0×0——绕过法：手动 `app.renderer.render(scene, app.camera)` + `domElement.toDataURL()` + POST 到本地接收服务。场景目录 CDN：`posemyart3.nyc3.cdn.digitaloceanspaces.com/scenes/premade_scenes_list.json`（5642 场景）。黄色箭头=方向光 gizmo（材质 r=g=1,b<0.1）可 traverse 隐藏。免费档=基础模型/IK/相机/方向光/OpenPose 导出；.obj 导出与动漫模型包在 Pro。
