# 专业剪辑与声音（H3 适配）

剪辑不是用来补救生成失败的。表演不可用、身份漂移、动作没落地时，先回 `h3-generate` 重做或简化；这里处理的是已合格镜头之间的顺序、切点、声音和统一调色。

## 1. 切点先服从情绪与故事

Walter Murch 的 Rule of Six 把剪辑判断按优先级排序。百分比是他的经验权重，不是数学公式；它的用处是提醒你：技术连续性排在最后，不要为了完美轴线牺牲一个真实反应。

| 优先级 | 权重 | 判断问题 |
|---|---:|---|
| Emotion | 51% | 这一刻观众应该感觉什么？切完情绪对不对？ |
| Story | 23% | 这一刀是否推进故事或揭示新信息？ |
| Rhythm | 10% | 切点是否落在有呼吸的节奏上？ |
| Eye-trace | 7% | 观众视线在画面里的落点是否接得上？ |
| 2D plane of screen | 5% | 左右、上下、构图关系是否稳定？ |
| 3D space | 4% | 人物在空间里的位置是否成立？ |

- 情绪和故事不过关，180°、30°、动作匹配再完美也是坏切。
- 为了保留一个真实反应，可以用插入镜头、中性镜头或声音桥掩盖空间不连续；不要反过来删掉反应。
- 技术连续性差到观众出戏时，才回到轴线、动作相位和构图匹配去修。

## 2. 切点语法

| 切法 | 什么时候用 | H3 后期动作 |
|---|---|---|
| Cut on action | 动作进行中，下一镜接同一相位 | 找动作中段；不要切在起手前或收势后 |
| Cut on blink/reaction | 听完、说完、眨眼、呼吸变化 | 让台词落地，再切听者反应 |
| Match cut | 跨时间/空间，用形状、动作或声音连接 | 选一个可复现的锚点动作：开门、放手、转头 |
| J cut | 下一镜声音先入 | 音频提前 2–4 帧，画面仍在前一镜 |
| L cut | 上一镜声音延后 | 音频延后 2–4 帧，画面已切到下一镜 |
| Sound bridge | 用连续环境/音乐跨场景 | 环境底床不重启，接缝交叉淡化 20–50 ms |
| Musical punctuation | 有 BGM 时 | 切在乐句重音或停顿，不要每拍都切 |

补充规则：

- **不要切在**手势起手前、人物刚入画未站稳、台词第一个音节上；除非故意制造打断。
- 台词说完留 0.3–0.5 秒再切；让听者反应，不要让画面抢在情绪前面。
- 一个情绪事件不要碎成很多角度。一个人听到坏消息，先让她听完；连续切五个表情通常比一个稳定的 hold 更弱。
- 快切需要静止来对比。全片都在切，等于没有节奏。
- 单条多镜 H3 的切点已经烧在画面里：后期只做头尾修剪、验证切点和声音，不要重新拆成逐镜 coverage。
- 逐镜拼接时，动作相位和屏幕方向必须匹配；接不上就用插入镜头、中性镜头或声音桥，不要硬切两个相反方向。

## 3. 节奏与单调审计

- 文戏快切默认 3–5 秒一个视觉段；10 秒 3–4 拍，允许一个 6–8 秒的 hero hold。动作戏默认 5 秒生成单元，段内 1–3 个视觉段。
- 1–2 秒的短拍只用于冲击、信息插入或笑点；不要连续三个短拍。
- 用快—慢—快或慢—快—慢做曲线；不要整条按同一个节拍器。
- 每刀只承担一个想法。没有新信息的镜头，删掉。
- 连续三个切点同景别、同机位方向或同一种运动，视为模板化；重排 coverage 或换一个反应拍。
- 至少保留一个静止反应拍；让观众有时间把信息落地。
- 不要为了“节奏快”切掉动作完成态；动作没落地，下一镜会像跳过了一段。

## 4. 声音四层

| 层 | 作用 | 写法/混音 |
|---|---|---|
| Dialogue | 信息与表演 | 原生 H3 台词；不做后期 TTS；对白最清楚 |
| SFX | 具体动作的物理声 | 一个动作一个主要 SFX；不要每个脚步都加 |
| Ambience | 空间与连续底床 | 2–3 个元素；整条连续，不按镜头重启 |
| BGM | 观众情绪 | 用户没要求就不加；写乐器、速度、动态 |

- **透视**：写 near/far、画内/画外、隔墙/隔玻璃；同一动作在不同距离要有不同空间感。
- **room tone**：每个地点铺一条房间底噪；接缝处交叉淡化 20–50 ms，不要用静音补洞。
- **sound bridge**：下一场的声音可以提前 2–4 帧进入；上一场的声音也可以延后 2–4 帧出。
- **silence**：重击、决定、开门前留 0.3–0.8 秒静音；静音是设计，不是缺轨。
- **one master track**：整条成片一条主音轨；不要逐镜 loudnorm，不要把一个场景拆成多条独立音轨后硬拼。
- 对白优先：先保证台词清楚，再谈音乐和整体响度；BGM 不得盖过人声。
- 原生台词镜头不要再叠第二层人声、TTS 或旁白解释。

响度仍按本项目规则：整条只做一次 `loudnorm`；编码目标 `I=-13.7, TP=-1.8`，成片验收 `-14 LUFS / -1.5 dBTP / LRA 11`；不要用 `alimiter` 代替响度归一。细节见 [`audio.md`](audio.md)。

## 5. 统一调色

分批生成的镜头，色差往往比剪辑点更先被观众发现。

- 先统一黑白电平、白平衡、对比和饱和度，再谈风格 LUT。
- 以肤色为锚点；脸不能一会儿灰绿、一会儿橙红。
- 用示波器/直方图看黑位和高光，不要只看监看器上的“感觉”。
- 调色用于统一和情绪，不用于掩盖身份漂移、换装或光线方向错误；这些回生成端解决。
- 接缝两侧对比同一帧：黑位、白平衡、饱和、颗粒、暗部细节。
- 不要过度加颗粒、辉光、暗角来“统一”；压缩后容易变脏。
- 交付前用同一播放器/解码链看一遍，避免调色软件与播放器色彩管理不一致。

## 6. QA 与交付

1. 整片从头到尾看一遍；技术指标合格不等于内容可用。
2. 单条多镜只核对请求切点 ±0.5 秒，不做全片阈值扫；切点变成连续运镜但仍有清楚视觉段，按视觉段验收。
3. 抽每个接缝前后各一帧：无黑帧、花屏、错序、重复帧。
4. 听接缝：无爆音、无底噪跳变、无音乐重启；对白清楚。
5. 核对响度与真峰值；确认整条只做了一次 loudnorm。
6. 核对字幕措辞、语言、同步；无台词就不加字幕。
7. 报告实际视觉段数、切点、时长、分辨率、帧率、音轨与响度；不要把“计划切点”当成“实际切点”。
